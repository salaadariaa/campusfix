# CampusFix

Proiect realizat de echipa **DID** pentru disciplina **Inginerie Software II**.

CampusFix este o aplicație web prin care studenții pot semnala probleme din campus, precum un videoproiector defect sau mobilier deteriorat, și pot urmări rezolvarea lor.

## Funcționalități planificate

- **Studenții** se pot autentifica, pot trimite o sesizare cu locația și descrierea problemei și pot urmări starea sesizărilor proprii.
- **Personalul de întreținere** poate vedea toate sesizările, le poate filtra după locație și stare și le poate actualiza pe măsură ce intervine.

## Fluxul unei sesizări

1. Studentul trimite sesizarea, iar aceasta primește starea **Nouă**.
2. Personalul de întreținere preia sesizarea și o marchează **În lucru**.
3. După remedierea problemei, sesizarea este marcată **Rezolvată**. Studentul vede starea actualizată în pagina **Sesizările mele**.

## Organizarea proiectului

Codul și documentația sunt gestionate în acest repository. Sarcinile și progresul echipei sunt urmărite în Jira.
